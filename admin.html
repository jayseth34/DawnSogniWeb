Connect to your site

Changes are saved straight to your GitHub repository, and the site updates about a minute after you publish. This needs a GitHub access key that can only edit this one repository.

How to get an access key (2 minutes)
  1. Open GitHub → New fine-grained token (signed in as the repo owner).
  2. Name it "Dawn Sogni admin". Expiration: up to a year.
  3. Repository access: Only select repositories → DawnSogniWeb.
  4. Permissions → Repository → Contents: Read and write. Nothing else.
  5. Generate, copy the key, paste it above.

The key is kept only in this browser. Anyone with it can edit your site's files, so don't share it. You can revoke it on GitHub any time.
